# YUVK Attendance System

YUVK Attendance System is a web-based attendance management application built using **HTML, CSS, and JavaScript**.  
It stores attendance data in the browser using **Local Storage** and generates detailed reports with graphs and PDF downloads.

---

## 🚀 Features

- 📅 Daily Attendance Tracking  
- 📊 Monthly & Yearly Attendance Reports  
- 📈 Graphical Representation (Charts & Percentages)  
- 🧮 Attendance Percentage Calculation  
- 📄 Download Attendance Report in PDF Format  
- 📥 Import Attendance Records  
- 💾 Data Stored in Browser Local Storage (No Database Required)

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- Local Storage API  
- Chart Library (for graphs)  
- jsPDF (for PDF report download)
